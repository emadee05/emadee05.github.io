# Multi-Layer Portfolio Website

A portfolio website built with React and TypeScript featuring a three-layer horizontal scrolling design.

## made with love

- React 18
- TypeScript
- Vite
- CSS3 with animations
- Google Fonts (Playfair Display, Inter)

## i mean if you want to . ? 

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
